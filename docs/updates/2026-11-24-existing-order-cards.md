# Photos and payments on existing order cards

When a store photograph changes, the order assistant can update the photograph on the existing staff message. A saved link between the order line and its message keeps multi-item orders in order. The receipt lists recorded discounts, coupon deductions, wallet credit, gateway payments and offline payments separately.

Tests decoded real image bytes and exercised an edit of the same message through a local transport. Receipt formatting was checked against a read-only sample of store orders.

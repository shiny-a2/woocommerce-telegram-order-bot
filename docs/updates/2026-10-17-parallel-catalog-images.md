# Product data and images can begin together

New spreadsheet references no longer need to wait for the edited product workbook before image discovery begins. The existing job can find and validate source images while the product data is being reviewed, then reuse those files after the approved draft is created. This shortens the wait between review and desktop image editing without changing the operator's approval steps.

The update uses the current source priorities and image-quality checks. A missing or unavailable image source is recorded for retry and does not block the product-data workbook. Product creation, desktop handoff, media upload, and publication still follow their existing approval gates. Source and desktop outcomes depend on the configured sites and operator workflow; this update does not assert that every submitted reference already has a complete image set.

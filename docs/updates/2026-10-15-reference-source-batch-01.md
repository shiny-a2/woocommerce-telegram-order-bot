# Reference-source verification: first batch

Five configured watch-reference sites were checked with a real model each for
product matching, specification extraction, and image quality. Two delivered
complete sample results. A third delivered data and an image for a site-format
reference but needs careful matching to the catalog's model format. Two sites
currently restrict automated product-page access, so their coverage is not
presented as working.

The connector now recognizes a product-page bot challenge as a temporary source
failure and records a retry delay instead of treating the watch as missing. A
large product feed is also read with a source-specific limit. Existing source
priorities and the spreadsheet approval workflow remain in place. More sites
will be checked in five-site batches; this update does not claim full catalog
or publication-path coverage.

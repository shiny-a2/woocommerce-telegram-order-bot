# Product source coverage and Excel-first intake

The existing product and image pipeline now supports additional official watch-source formats with exact reference checks. A source configuration change can retry earlier no-match work, while bounded batches and per-brand rotation prevent one large backlog from monopolizing discovery.

Operator-submitted product spreadsheets take priority over background missing-image and gallery work. New references produce reviewable product workbooks; draft creation requires explicit spreadsheet approval, and publication remains a separate step. Site-specific mapping notebooks remain editable and require confirmation before their rules are applied.

The update was exercised with real public source pages and isolated catalog, transport, and recovery regression suites. Manual desktop image processing remains part of the workflow. Some third-party sources restrict automated access, and a partial gallery is not yet guaranteed to be supplemented from a second source.

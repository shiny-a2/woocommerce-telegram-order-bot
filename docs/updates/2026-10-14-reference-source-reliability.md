# Reference source reliability update

The product and image pipeline now recognizes more source-site formats from its existing admin priority lists. It can use an exact product search where catalogue URLs omit model numbers, read compressed product sitemaps, and retain a complete gallery when a page publishes multiple product-data blocks.

The update also tightens image selection for a reviewed retailer so packaging and duplicate size variants do not enter a watch gallery. Product matches still require exact model evidence, and data remains subject to the existing spreadsheet review and approval workflow.

Live checks confirmed product-data extraction, image discovery, and priority fallback on representative watch references. Some configured third-party sites block automated requests or have incomplete feeds; their coverage remains unverified and the pipeline continues to later sources when possible. No automatic publication or desktop editing behavior changed.

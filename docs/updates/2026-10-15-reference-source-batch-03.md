# Reference-source verification: third batch

Five more configured watch-reference sites were sampled on the live bot host
using exact model numbers. Two supplied both specifications and qualifying
product images. Two supplied product specifications; their sampled brands do
not use those sites as automatic image sources in the current admin settings.
The fifth site rate-limited the server, so it remains unverified for automatic
collection.

The image checks decoded and validated the downloaded files, including a
fallback from a small preview to a larger product image. Source priorities and
approval rules were unchanged. Fifteen of 44 configured domains have now been
sampled. These checks did not publish products or exercise the Windows image
workflow.

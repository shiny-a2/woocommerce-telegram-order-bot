# اسپکِ اندپوینتِ افزونهٔ CRM: درجِ خودکارِ تصاویرِ محصول + متادیتای سئو

**چرا لازم است:** ربات می‌تواند عکسِ شاخص/گالری را با wc/v3 ست کند، اما **نمی‌تواند متادیتای رسانه (alt/title/caption/description) را بنویسد** — کلیدِ ووکامرس برای نوشتنِ `wp/v2/media` مجاز نیست (HTTP 200 می‌دهد ولی ذخیره نمی‌کند) و میزبان هدرِ Authorization را روی نوشتن strip می‌کند (پس Application Password هم جواب نمی‌دهد). فیلدِ **description = نامِ کاملِ محصول** برای سئو لازم است. راهِ درست: افزونه سمتِ سرور با توابعِ بومیِ وردپرس این کار را بکند.

## اندپوینت
```
POST /wp-json/a2crm/v1/tg/product-images
```
**احرازِ هویت:** همان الگوی بقیهٔ اندپوینت‌های `a2crm/v1/tg/*` (مثلِ `/finance`) — پارامترها در **query-string** (میزبان بدنه را strip می‌کند)، با همان شرطِ دسترسیِ فعلی.

**ورودی (query-string):**
- `product_id` (int) — یا `ref` (string). اگر `product_id` داده شد، رفرنس از اتریبیوتِ `pa_رفرانس` (یا آخرِ عنوان) استخراج شود.
- اختیاری `dry_run=1` — فقط تطبیق را گزارش کن، چیزی ننویس.

## رفتار (سمتِ سرور، برای یک محصول)
۱. محصول را با `product_id` بگیر؛ `title` و `ref` را دربیاور. اگر `ref` خالی → خطا `no_ref`.
۲. در کتابخانهٔ رسانه، پیوست‌هایی را پیدا کن که **نامِ فایلشان دقیقاً** این الگوها باشد (پسوند webp/jpg/jpeg/png، حساس‌نبودن به بزرگی/کوچکی):
   - عکسِ شاخص: `<ref>.<ext>`
   - گالری: `<ref>-1.<ext>`، `<ref>-2.<ext>`، … (به ترتیبِ عددی)
   جست‌وجو بر اساسِ نامِ فایل (`_wp_attached_file` / `post_title` / `guid`)، نه فقط search عمومی. **تطبیقِ دقیق** — هرگز فایلِ رفرنسِ دیگری برداشته نشود.
۳. اگر عکسِ شاخصِ دقیق پیدا نشد → **هیچ تغییری نده**، خطا `no_featured` برگردان.
۴. اگر پیدا شد:
   - `set_post_thumbnail(product_id, featured_id)` — عکسِ شاخص.
   - متای `_product_image_gallery` محصول = idهای گالری با کاما (فقط `-1,-2,…`؛ **شاخص هرگز در گالری تکرار نشود**).
   - برای **هر** پیوست (شاخص + گالری) هر چهار فیلد = **عنوانِ کاملِ محصول، عیناً**:
     - `post_title` (عنوان)
     - متای `_wp_attachment_image_alt` (متن جایگزین)
     - `post_excerpt` (توضیح مختصر / caption)
     - `post_content` (توضیح / description)  ← این همان چیزی است که فقط از این راه نوشتنی است.
   - (پیوست‌ها لازم نیست به‌عنوانِ فرزندِ محصول ست شوند؛ فقط thumbnail/gallery + متادیتا.)
۵. **هیچ‌چیزِ دیگری** از محصول را دست نزن: قیمت، عنوانِ محصول، توضیحات، ویژگی‌ها، دسته، برند، برچسب، موجودی، وضعیتِ انتشار.

## خروجی (JSON)
```json
{
  "product_id": 292898, "ref": "LC08219.550",
  "featured_set": true, "gallery_count": 2,
  "images_updated": 3,          // تعداد پیوست‌هایی که ۴ فیلدشان تکمیل شد
  "title": "ساعت مردانه لی کوپر LC08219.550",
  "error": null                 // یا "no_ref" / "no_featured"
}
```

## نکات
- **ایدمپوتنت:** اجرای دوباره روی همان محصول نتیجهٔ یکسان بدهد (بدونِ تکرارِ گالری).
- فقط دادهٔ تخت؛ رباتِ ما این را per-product صدا می‌زند و گزارشِ اکسل جمع می‌کند.
- اگر ابهام/عدم‌تطابق بینِ رفرنس و نامِ فایل بود → تغییری نده و در `error` علت بده.
- (اختیاری ولی مفید) نسخهٔ دسته‌ای: `product_ids=1,2,3` → آرایه‌ای از همین خروجی، تا رفت‌وبرگشتِ کمتر.

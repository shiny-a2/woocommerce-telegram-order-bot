# Clearer sales receipts

Counter sales now group items, payment methods and totals. A receipt shows the amount paid with each method when the recorded split balances. Staff can see which allocations still need clarification.

New sale alerts include the customer's club tier, active points, redemption value and wallet balance. Website and counter teams use the same labels. Revised receipts keep their existing conversation and product photo.

Synthetic tests covered corrected payments, photo captions, long orders, unavailable balances and ordinary sale edits. The companion commerce tests exercised repeated purchases, refunds and staff access boundaries.

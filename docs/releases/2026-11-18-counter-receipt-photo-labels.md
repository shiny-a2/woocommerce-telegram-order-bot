# Match counter receipt photos to invoice lines

A receipt with two watches can include a second photo as a reply. Each photo now shows which invoice line it belongs to, with the product reference when available. If the first watch has no matched image, the cover identifies the later line it depicts. Photos shared by several lines list those positions together. The invoice heading carries the recorded sale, exchange or return classification.

When an invoice correction removes a photo, the bot removes the obsolete reply or replaces it with a correction notice if Telegram refuses deletion. A local replay of a two-watch receipt from the previous release updated both existing captions in place. Repeating the replay produced no further messages or edits.

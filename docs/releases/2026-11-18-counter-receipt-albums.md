# One photo album per counter receipt

A counter receipt with two or three matched watch photos can now show them together. The caption identifies the item pictured in each position. If a reviewed correction changes a watch, its image and receipt text can be updated in the existing album. Album size changes require a replacement group of photos. Supporting exchange documents point staff to the corrected purchase.

Isolated tests checked multi-watch receipts, corrected photos, repeated imports and recovery from an uncertain delivery. A local checkout receipt was passed to the delivery worker using a simulated messaging service.

The released worker also converted existing two-watch receipts. Delivery checks confirmed two photos in each album and routing to the corresponding branch topic.

# ایستگاهِ ادیتِ خودکارِ عکسِ محصول

عکس‌های خام روی این کامپیوتر با فتوشاپ ادیت می‌شوند و خروجی به سایت می‌رود — **بدونِ اینکه کسی
پشتِ سیستم بنشیند و کلیک کند**. تنها چیزی که این کامپیوتر لازم دارد فتوشاپِ نصب‌شده و روشن‌بودن است.

```
        سرور                     ایستگاهِ طراحی (این کامپیوتر)              سرور
   خام‌های آماده  ──دانلود──►  inbox ──[فتوشاپ، خودکار]──► outbox ──ارسال──► staging
                                                                              │
                                                    کتابخانهٔ رسانه ← ورود ←──┘
                                                    اتصال به محصول + سئو
```

## چه چیزی روی این کامپیوتر تغییر می‌کند؟
هیچ‌چیز جز یک پوشه (پیش‌فرض `C:\psagent`). اسکریپت:

* فایلی روی سایت نمی‌نویسد،
* به دیتابیس و وردپرس دسترسی ندارد،
* فقط از پوشهٔ `inbox` می‌خواند و در `outbox` می‌نویسد.

## نصب (یک‌بار)

۱. پوشهٔ `psagent` را روی کامپیوتر کپی کن.
۲. دو فایلِ قالبِ `.psd` (هیرو و پس‌زمینهٔ گالری) را در `C:\psagent\templates` بگذار.
۳. در پاورشل:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

۴. آمادگی را چک کن:

```powershell
powershell -ExecutionPolicy Bypass -File .\psagent.ps1 -Preflight
```

اگر پیامِ «همه‌چیز آماده است ✅» آمد، تمام است.

## اجرا

```powershell
# یک دور: هر چه در inbox هست ادیت شود
powershell -ExecutionPolicy Bypass -File .\psagent.ps1

# حالتِ خودکار: مدام inbox را می‌پاید
powershell -ExecutionPolicy Bypass -File .\psagent.ps1 -Watch

# فقط وضعیت
powershell -ExecutionPolicy Bypass -File .\psagent.ps1 -Status
```

برای اینکه با روشن‌شدنِ ویندوز خودش بالا بیاید، هنگامِ نصب `-RegisterTask` را اضافه کن.

## قواعدِ نام‌گذاری (مهم)

* `REF.jpg` → عکسِ **شاخص** + اولین عکسِ **گالری** (`REF-1.jpg`)
* `REF-1.jpg` → عکسِ دومِ گالری (`REF-2.jpg`)، `REF-2.jpg` → سومی، و همین‌طور

رفرنس‌هایی که خودشان خط‌تیره دارند (مثلِ `16-6018-13-007`) درست تشخیص داده می‌شوند: «`-N`» فقط
وقتی شمارهٔ گالری است که فایلِ پایه هم در همان پوشه باشد.

## اگر کاری نیمه‌کاره ماند

اسکریپت **از همان‌جا که مانده ادامه می‌دهد**: هر خروجی‌ای که از قبل در `outbox` باشد دوباره ساخته
نمی‌شود. پس بستنِ ناگهانیِ فتوشاپ یا ری‌استارتِ ویندوز چیزی را خراب نمی‌کند؛ فقط دوباره اجرا کن.

## اگر عکسی خطا داد

فایلِ خروجیِ ناقص **ذخیره نمی‌شود** (تضمینِ اسکریپت: هیچ عکسی با پس‌زمینهٔ خرابِ سفید ذخیره نمی‌شود).
فهرستِ خطاها اینجاست:

```
C:\psagent\logs\failed.tsv
```

شایع‌ترین علت: عکسِ خام پس‌زمینهٔ سفیدِ یکدستِ متصل ندارد، یا خودِ ساعت تا لبهٔ کادر آمده.
این‌ها را باید دستی ادیت کرد.

## گزارشِ کار

```
C:\psagent\logs\psagent.log
```

## پرسش‌های رایج

**فتوشاپ باید باز باشد؟** نه. خودش باز می‌کند. اگر بازِ باشد هم مشکلی نیست، ولی وسطِ کار روی همان
فتوشاپ کارِ دیگری نکن.

**کامپیوتر کند می‌شود؟** بله، در حینِ پردازش CPU درگیر است. `batch_size` را در
`psagent.config.json` کم کن تا سبک‌تر شود.

**ارسالِ خودکار به سرور روشن است؟** فقط اگر `auto_push` در تنظیمات `true` باشد و کلیدِ ارسال نصب
شده باشد. وگرنه خروجی‌ها در `outbox` می‌مانند و دستی تحویل داده می‌شوند.
